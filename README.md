# Finolex Events Website - Brainwaves 2026

Welcome to the official repository for the **Finolex Academy of Management and Technology (FAMT)** events website, **Brainwaves 2026**. This project showcases the various technical and non-technical events, schedules, and galleries for the annual college fest.

## 🚀 Features

-   **Modern UI/UX**: Built with a "Cyberpunk/Sci-Fi" aesthetic using Tailwind CSS.
-   **Events Showcase**: Detailed cards for all competitions (BrainByte, Kalakruti, Stabila) with "Register" and "Details" options.
-   **Responsive Design**: Fully optimized for desktop and mobile devices.
-   **Interactive Elements**: GSAP animations, glassmorphism effects, and smooth transitions.
-   **Contact & Location**: Integrated Google Maps and contact details for easy navigation.

## 🛠️ Tech Stack

-   **Frontend**: React.js, Vite
-   **Styling**: Tailwind CSS
-   **Animations**: GSAP
-   **Icons**: Heroicons / React Icons

## 📦 Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/TejasRawool186/finolex-events-website.git
    cd finolex-events-website
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```
